Diálogos básicos

Diálogo simple Contenido básico Un diálogo con contenido de texto y un header con icono. Con acciones Botones en el footer Diálogo con botones de acción configurados en la parte inferior. Confirmación Dialogo de confirmación Diálogo para confirmar acciones críticas con header de advertencia.

Variantes de header

Header con color Colores personalizados El header puede tener diferentes colores: primary, secondary, accent, error, success, warning, info, dark. Datos personalizados Injectar datos Los diálogos pueden recibir datos personalizados que se inyectan en el contenido.

Comportamiento

Cierre deshabilitado No se puede cerrar Diálogo que no se puede cerrar haciendo clic fuera o presionando Escape. Pantalla completa Ocupa toda la pantalla Diálogo que ocupa toda la pantalla del dispositivo. Tamaños xs, sm, md, lg, xl, xxl Diferentes tamaños predefinidos para adaptarse al contenido. Validación antes de cerrar beforeClose en titlebar El contenido valida antes de permitir cerrar con el botón X del header. Maximizable Botón maximizar/restaurar Diálogo con botón para alternar entre tamaño normal y pantalla completa sin cerrar.
